# Commands

| Command | Use when you want to know |
| --- | --- |
| [`search`](search.md) | where an address, prefix, port, URL, user or name appears |
| [`lookup`](lookup.md) | what a rule, an object or an application contains |
| [`simulate policy`](simulate-policy.md) | whether your firewalls allow a flow, and which rule decides on each hop |
| [`simulate nat`](simulate-nat.md) | which NAT rule a packet hits, and what the packet looks like after it |
| [`simulate routing`](simulate-routing.md) | which firewalls a packet crosses, and through which zones |
| [`snapshot`](snapshot.md) | which snapshots you have, and what changed between two of them |

| Command | Use when you want to |
| --- | --- |
| [`fetch`](fetch.md) | store a new snapshot of your firewalls |
| [`inventory`](inventory.md) | create the inventory file |
| [`mcp`](mcp.md) | serve the questions to an agent over MCP |

Every command takes the [global flags](../reference/global-flags.md).
